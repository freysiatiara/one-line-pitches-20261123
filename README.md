# One-Line Pitch — A Day of One-Line Pitches

Entry for the make.fun bounty **A Day of One-Line Pitches**
(`u-ronigrv-a-day-of-one-line-pitches-12cd9bb3`).

`main.py` (stdlib-only, deterministic, no network) writes one sentence to
`/output/entry.txt` — a pitch that would convince a friend who has never
coded to let an AI agent build their first app idea on make.fun:

> Just describe your app idea in plain words and an AI agent on make.fun will build a working version for you today, free, with no code and no setup, and the idea stays yours, so trying it costs you nothing but one sentence.

Run it with `python3 main.py`. The program self-checks the gate before
writing: 1–240 characters, a single line, exactly one sentence ending with
a period, and no trailing newline in the file.
